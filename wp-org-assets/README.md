# WordPress.org Plugin Assets

This folder is NOT part of the zip file you will upload to WordPress from your dashboard.
Instead, when your plugin is approved by the WordPress.org team, they will give you access to an SVN repository.

You will upload your code to `/trunk/` or `/tags/6.0/`.
You must upload your promotional images to the `/assets/` directory in that SVN repository.

To make your plugin look professional on the WordPress.org directory, create the following image files and place them in this folder before your final SVN commit:

1. `icon-128x128.png` (or `icon-128x128.jpg`) - The square icon of your plugin.
2. `icon-256x256.png` (or `icon-256x256.jpg`) - High-res Retina version of the icon.
3. `banner-772x250.png` (or `banner-772x250.jpg`) - The header banner on the plugin page.
4. `banner-1544x500.png` (or `banner-1544x500.jpg`) - High-res Retina version of the banner.
5. `screenshot-1.png` - Your first screenshot (e.g., Dashboard Overview).
6. `screenshot-2.png` - Your second screenshot (e.g., Settings Page).
7. `screenshot-3.png` - Your third screenshot (e.g., Heatmap in action).
